# 📊 Portfolio Optimization & Risk Analytics

## 🔍 Overview
This project builds an optimized stock portfolio using Python by maximizing risk-adjusted returns and comparing performance with the NIFTY 50 benchmark.

## ⚙️ Features
- Portfolio optimization using Sharpe Ratio
- Efficient Frontier visualization
- Risk analysis using covariance and correlation
- Benchmark comparison with NIFTY 50

## 🧠 Methodology
- Data Source: Yahoo Finance
- Optimization: SciPy (SLSQP)
- Metrics:
  - Expected Return
  - Volatility
  - Sharpe Ratio

## 📈 Results
- Achieved better risk-adjusted returns than market benchmark
- Demonstrated diversification benefits

## 🛠️ Tech Stack
Python, Pandas, NumPy, Matplotlib, SciPy

```bash
pip install -r requirements.txt
